# ISM2411 Lab 12 — Read a Sales CSV, Write a Cleaned Report

**Name:** Audra

## How to Run

From this folder, run:

```bash
python csv_practice.py
```

## Description

This lab practices reading and writing CSV files using Python.

The exercises include:
- Reading CSV files with csv.reader.
- Skipping header rows.
- Calculating sales revenue.
- Filtering and writing cleaned CSV files.
- Using csv.DictReader.
- Creating sales summary dictionaries.
- Logging program runs with append mode.
